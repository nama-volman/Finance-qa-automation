Money transfer, verified through the API

All API checks passed

The UI tests check what the user sees. This flow checks that the money really moves: two real accounts, one transfer, and every side effect confirmed in the backend. Negative cases cover sending to yourself, an unknown or malformed email, and insufficient funds.

  1. 1Get tokensBoth users sign in through Supabase Auth
  2. 2LookupSender finds the receiver by email
  3. 3Quotecreate_transfer_quote locks rate for 60s
  4. 4Executeexecute_transfer with an idempotency key
  5. 5BalancesSender -amount, receiver +converted amount
  6. 6HistoryTransfer appears in receiver's list
  7. 7NotifyOne payment_received notification
  8. 8UISender's dashboard Total balance drops by the amount

Bugs found in the app

Marked xfail(strict=True): the test passes the build while the bug exists, and turns red the day it is fixed, so the marker can be removed.

  • Cannot add duplicate bank accountBUG: the site allows adding the exact same bank account twice
  • Cannot add duplicate cardBUG: the site allows adding the exact same card twice
  • Clear resets all filtersBUG: Clear resets Type but Currency keeps the old value; there is also no 'All currencies' option

Skipped on purpose

These tests check their precondition against the live account first and skip when it does not apply, instead of failing for the wrong reason.

  • Add wallet opens and cancel closes dialogThe account already has 4 wallets - Add wallet is disabled
  • Convert from preferred currency (EUR)EUR is the preferred currency
  • Convert to preferred currency (EUR)EUR is the preferred currency
